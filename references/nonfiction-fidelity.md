# 非虚构事实保真协议 (Nonfiction Fidelity)

> 适用于纪实特稿、调查、人物报道、回忆录中的事实性段落。目标是防止“为了生动而脑补”。

## 1. 事实细节分级

每个可被读者理解为真实发生过的细节，都必须归入一类：

- **SOURCE**：材料直接给出，可直接写。
- **PARAPHRASE**：材料语义明确，可改述但不得增强事实强度。
- **DERIVED**：可由材料确定性计算得到，例如 `2026 - 2017 = 9`；必须保留计算依据。
- **RECONSTRUCTED**：材料没有逐字记载，但用户明确授权基于多条证据重构；正文应避免伪装成精确目击。
- **UNKNOWN**：没有依据，不得写成事实。

人物族群、车辆品牌、服装颜色、天气、灯光、气味、微动作、台词、路线、距离、价格、心理活动都属于事实细节，不能因为“只是氛围”就默认自由补写。

### Source Policy

开稿对齐卡同时锁定：

- `closed_corpus`：只能使用用户提供 / 当前材料内的信息；
- `external_verify`：允许额外检索核验，但新增来源必须可追溯；
- `reconstruction_policy=forbidden`：默认，不重构缺失现场；
- `allowed_with_label`：只有用户明确授权时使用，且不能把重构伪装成精确目击；
- `unknown_policy=omit`：非关键未知默认不写；
- `flag`：保留为编辑缺口；
- `ask_if_blocking`：只有缺口直接阻塞核心命题时才询问用户。

## 2. Claim Ledger：事实强度守恒

容易被模型“顺手强化”的不只有名词属性，还包括因果、动机和心理。关键主张必须记录：

| Claim ID | 类型 | 正文允许的最强表述 | 来源 | 证据状态 |
| :--- | :--- | :--- | :--- | :--- |
| C1 | FACT | “2017 年毕业” | S1 | DIRECT |
| C2 | CAUSAL | “她将离职决定部分归因于体检经历” | Q3 | ATTRIBUTED |
| C3 | MOTIVE | “她说摆摊是为了还债” | Q5 | ATTRIBUTED |
| C4 | PSYCHOLOGY | “她回忆当时感到害怕” | Q7 | ATTRIBUTED |

主张类型至少区分：

- `FACT`：可核验事件、数字、身份；
- `CAUSAL`：A 导致 B；
- `MOTIVE`：人物为什么行动；
- `PSYCHOLOGY`：人物内心、感受、认知变化；
- `INTERPRETATION`：作者 / 编辑分析。

证据状态：

- `DIRECT`：材料直接支持；
- `ATTRIBUTED`：只能写成“某人说 / 回忆 / 认为”；
- `DERIVED`：确定性计算；
- `INFERRED`：只有用户允许推断时才可使用，并保持推断语气；
- `UNKNOWN`：不得写成事实。

**Strength conservation**：改写不能把 “可能 / 据称 / 她认为 / 部分原因” 提升为 “就是 / 证明 / 因此 / 唯一原因”。

## 3. 时间轴与算术

写稿前建立绝对时间轴：

| ID | 绝对时间 | 事件 | 来源 |
| :--- | :--- | :--- | :--- |
| T1 | 2017 | 毕业 | |
| T2 | 2019 | 生子 / 负债 | |
| T3 | 2024 | 体检 | |
| T4 | 2026 | 当前摆摊 | |

正文出现“X 年前 / X 年后 / 多大年龄 / 持续几年”等派生时间时：

1. 找到两个绝对锚点；
2. 显式做减法或加法；
3. 把结果写入 Derived Facts；
4. reviewer 再独立复算一次。

无法确定时写绝对年份，**不要凭感觉生成相对年数**。

## 4. 实体属性锁

为关键实体建立属性表：

| 实体 | 已知属性 | 来源 | 未知 / 禁止脑补 |
| :--- | :--- | :--- | :--- |
| 旧车 | “旧车” | S3 | 品牌、型号、颜色 |
| 烤面筋摊主 | “小哥” | S8 | 民族、年龄、籍贯 |
| 邻摊赠物 | “一把葱” | S9 | 羊肉汤、其他菜品 |

正文只能消费“已知属性”。未知列不是创作邀请，而是**禁止擅自补全区**。

## 5. 原话保真

所有采访原话分为：

- **VERBATIM**：逐字引用。保留口头禅、语法残缺、重复、停顿和方言；只允许修正明显转录错误。
- **LIGHT-CLEAN**：用户授权轻度整理，只修标点或口误，不把市井口语改成书面表达。
- **PARAPHRASE**：不加引号，以转述形式表达。

没有原话依据时，不得把模型编出的句子放进引号。

## 6. 叙事人称锁

对齐卡必须指定：

- 正文 POV：第一人称 / 第三人称 / 混合；
- 标题 POV：必须与正文一致，除非明确标注“第一人称专栏版 / 第三人称特写版”；
- 引语 POV 不影响正文 POV。

包装阶段不得为了点击率把第三人称报道擅自改成“我”。

## 7. 物象账本

核心物象不只是开头装饰。每个物象记录：

| 物象 | 首次出现 | 中段动作 | 后段回收 | 来源 |
| :--- | :--- | :--- | :--- | :--- |

“动作”必须是来源支持的动作，不能为了闭环捏造擦拭、抚摸、掉落、赠送等行为。

## 8. 最终核验

终稿交付前逐项核对：

- 每个关键 FACT / CAUSAL / MOTIVE / PSYCHOLOGY 主张是否没有超过 Claim Ledger 允许的证据强度；
- 每个精确数字、相对年份、人群标签、品牌型号是否有来源或确定性推导；
- 每句引号内对白是否存在原话来源；
- 每个核心物象是否完成来源内可支持的回收；
- 标题与正文 POV 是否一致；
- 为“生动”新增的环境 / 动作是否越过 SOURCE / RECONSTRUCTED 边界。
