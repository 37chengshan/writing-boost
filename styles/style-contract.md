# 模块化写作风格接口契约 (Modular Style Specification Contract)

> **版本**：`1.0.0`  
> **核心原则**：写作风格不可硬编码在引擎核心中。任何风格插件必须实现标准的六层 DNA 接口契约，以确保能够被流水线（阶段 0 至阶段 6）与多代理审查委员会无缝加载与质检。

---

## 1. 风格规范标准接口 (The 6-Layer Interface)

每个风格插件必须以 Markdown 或 YAML 规范形式定义，并包含以下六层接口实现：

```
┌────────────────────────────────────────────────────────┐
│ 风格元数据 (Manifest: ID, 名称, 体裁, 适用篇幅, 语调温度)  │
├────────────────────────────────────────────────────────┤
│ L1: 语言与句式规范 (词汇密度, 动词优先, 标点呼吸感, 禁用词)│
│ L2: 篇章叙事结构 (开篇 Hook, 分场推进阶梯, 终局收束模式) │
│ L3: 选题冲突张力 (核心反差张力轴, 题材禁区, 痛点挖掘)   │
│ L4: 素材与物理物象 (承重物象数量, 感官置身细节, 真实度守恒)│
│ L5: 认知底色与立场 (世界观, 道德立场, 共情模式, 认知破局) │
│ L6: 排版与多端衍生 (段落长度, 标题矩阵公式, 社交转译模版) │
└────────────────────────────────────────────────────────┘
```

---

## 2. 字段规范与实现要求

### 模块元数据 (Manifest)
```yaml
id: "style-id-slug"                     # 唯一标识符，全小写字母与短横线
name: "风格中文全称"                    # 如：纪实特稿·极致反差与物象锚定
version: "1.0.0"
genre: "适用体裁"                       # 如：深度非虚构 / 人物专访 / 行业特稿
ideal_length: "3000~5000字"             # 建议字数区间
emotional_temperature: "冷峻 / 苍凉 / 锐利 / 沉郁"
voice_tone: "客观克制 / 现场亲历 / 第一性审视"
```

### L1 表层语言规范 (Prose & Syntax)
- **句长分布**：明确短句（$\le 15$ 字）与逗号长句（30~60 字串联动作）的配比。
- **动词密度**：限制形容词堆叠，强制使用单动词推动事实。
- **对话风格**：方言保留度、口语粗粝感、心理独白比例。
- **专属禁用词与红线**：定义本风格特异性的 AI 腔与禁忌表述。

### L2 篇章叙事结构 (Narrative Arc)
- **开篇 15% Hook 公式**：规定开篇首段必须出现的微观冲突切片类型。
- **中段 70% 推进节拍**：场景切换时的电荷反转要求与现实代价机制。
- **结尾 15% 收束法则**：物象余响还是哲思留白，严禁哪种结尾。

### L3 选题与反差张力 (Conflict Tension)
- **核心反差轴**：列举本风格最擅长调动的 3~5 组社会或人性反差（如：草根突围 vs 阶层壁垒、体制狂热 vs 山野真实）。
- **题材定位与受众痛点**：触击哪种现实隐痛与心理投射。

### L4 素材与物象策略 (Sensory & Object Anchors)
- **承重物象要求**：全文必须锁定的具体物理物件数量（通常 $\ge 3$ 件）。
- **五感置身指令**：光线、声响、气味、触感的具体呈现标准。

### L5 认知框架与道德立场 (Cognitive Stance)
- **道德立场**：严禁道德居高临下，贯彻“反说教”、“零审判”或“冷静手术刀”。
- **价值增量**：为读者提供哪种不落俗套的认知突破（如：从道德指责转向制度/生存困境理解）。

### L6 排版与衍生包装 (Packaging & Delivery)
- **排版节奏**：段落视觉厚度（2~4 行黄金法则）。
- **标题矩阵**：定义 3~5 组符合该风格的爆款标题生成公式。
- **多端分发模板**：对应 X/小红书/公众号的转译逻辑。

## 3. 风格插拔与调度语法 (CLI & Workflow Integration)

- **查询所有可用风格**：`/writing-boost style list`
- **查看风格详情**：`/writing-boost style info [style-id]`
- **指定风格写稿**：`/writing-boost write [主题] --style [style-id]`
- **从模版新建自定义风格**：`/writing-boost style new [new-style-id]`
