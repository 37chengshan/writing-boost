# 场景化细纲与节拍表规范 (Scene Beat Sheet)

> 供 `/writing-boost shape` 或 `/writing-boost beats` 阶段使用。根据《选题与立项评估卡》选定的模式类型，调用对应细纲骨架推进。

---

## 一、通用节拍推进原则 (Progressive Beats Discipline)

1. **黄金开局 Hook（前 15% 篇幅）**：
   - 严禁铺垫客套、背景介绍或大段世界观；必须在前 300~500 字内直接切入极具反差的极端场景、公众争议切片或冷峻陈述。
   - 出场第 1 件承重物理物象。
2. **中间段落动作与冲突递进（15% ~ 85% 篇幅）**：
   - 严禁跳步写作（Never write ahead）；每次只敲定一个动作节拍。
   - 单段 2~4 行（80~120字），核心转折动作与粗粝台词单独成行。
   - 情绪必须通过生理极限动作（血丝、流汗、自扇巴掌、痔疮发作、晨露入腋、耳鸣反胃）呈现，杜绝抽象情绪形容词。
3. **终局收束与余韵（后 15% 篇幅）**：
   - 严禁空洞升华正能量与道德说教，必须收在具体的物理动作与生活物象上（端上一碗面、修船造桨、把自己活成靠山、洱海边的并肩背影）。

## 二、十二大叙事模型节拍细纲骨架

### 模式 A：【极端韧性·英雄特写型】（范例：赵家驹阿尔卑斯330公里夺冠）
```markdown
[节拍 1: 终局极端切片 Hook (0%~10%)]
- 场景与环境：凌晨雪山/极寒夜幕，头灯微光，两腿灌铅，满脸血污
- 极限生理动作：鼻血流了又干、咬舌头、自扇巴掌保持清醒；出场物象（沾满血痕的越野杖）
- 历史反差爆破：普通外卖小哥，破纪录打破欧美16年垄断夺冠

[节拍 2: 溯源与双重反差 (10%~25%)]
- 现实背景：从农村打工、外卖骑手到极限越野赛场；地表最残酷赛事TOR330规则介绍
- 赛前压抑与反常规物象：赛事强制要求的“裹尸袋”与极简装备

[节拍 3: 赛道对抗与技战术波折 (25%~45%)]
- 突发受挫：203公里补给站被对手反超，不慌不乱
- 技战术反击：夜间下坡发挥身材矮小冲击力小的强项，236公里夺回第一

[节拍 4: 生理崩塌与肉身死磕 (45%~70%)]
- 身体罢工：连续奔跑60多小时累计睡不足1小时，肠胃彻底拒绝进食
- 意志绝境：盯着头灯前一两米光晕，靠机械式拄杖前移

[节拍 5: 核心情感支柱与唯有一人的后勤 (70%~90%)]
- 拒绝团队宏大叙事：没有庞大后勤保障团，只有妻子一人开着房车、手捧电饭锅在补给点守候
- 患难羁绊：两人眼神交汇，微小温情支撑肉身死磕

[节拍 6: 终局留白与生活实感 (90%~100%)]
- 冲线瞬间与奖牌物象
- 余韵：落在具体的物理物象与回国后“想吃一碗热干面”上
```

### 模式 E：【阶层双轨·时代断裂与草根突围型】（2026 新增范例：《贾浅浅 vs 张雪》）
```markdown
[节拍 1: 双向强反差镜像切入 Hook (0%~15%)]
- 争议切片：文坛名家之女贾浅浅靠特权保驾一路破格晋升留校，引爆全网质疑
- 对照切片：26岁演员夏之光综艺自曝“家庭无能力兜底”，15岁出道交不起房租，父母拉黑一年半
- 核心台词：父母给得出爱，但给不出兜底；孩子感受到爱，但感受不到安全

[节拍 2: 时代共鸣铺设：四重兜底全面瓦解 (15%~35%)]
- 四重兜底瓦解：亲情兜底（父母养老不够）、体制兜底（大厂裁员/AI浪潮）、房产兜底（高位断供套牢）、养老兜底失效
- 微观承重案例：42岁财务主管李姐，发烧39度不敢请假，怕被年轻人和AI取代，每天活在恐惧中

[节拍 3: 特权对照组深度解剖：靠山虚妄与规则审判 (35%~55%)]
- “屎尿体”诗作风波、作协撤销资格
- 依附细节物象：偷偷把《我爱辣椒》放在父亲午睡书桌上拍马屁发表
- 终局反噬：学术论文涉嫌抄袭被查通报；揭示“所有的依附与退路，早已在暗中标好了代价”

[节拍 4: 草根对照组绝境深潜：撕咬突围与死磕自救 (55%~75%)]
- 绝境起点：湖南怀化19岁初中摩托修理工张雪，贫寒无靠
- 极地动作物象：骑破摩托冒雨追节目组采访车100多公里，单枪匹马雨中狂奔
- 死磕精神台词：“死马当活马医，只要我能逮得住，我就咬住了不松口”
- 17年逆袭：创立机车品牌，五一WSBK匈牙利站打破欧美日垄断夺冠

[节拍 5: 行动认知升华：从外部兜底到“碎银思维” (75%~100%)]
- 认知 1：认命，但不认输（承认失业/降薪/无人帮的客观困境，停止内耗）
- 认知 2：把安全感从外部转向内部核心生存能力
- 认知 3：“碎银思维”取代“黄金思维”（兼职、技能、低成本饮食习惯、微观爱好）
- 余音闭环：在风平浪静时，修船造桨；在无人可依时，把自己活成靠山
```

### 模式 F：【社会议题·群体隐痛与去病耻突围型】（2026 新增范例：《2.1亿女性的秘密》）
```markdown
[节拍 1: 显性舆论枷锁与性别双标 Hook (0%~15%)]
- 热搜争议切片：50岁李艾穿紧身瑜伽服街拍被骂“不得体”，伊能静穿短裙被骂装嫩
- 对照双标：周润发朴素爬山被赞低调儒雅，中年男明星发福被赞大叔魅力
- 揭开隐性现实：“得体”规训让全社会忽视中年女性正在经历无人共情的生理巨变

[节拍 2: 隐秘痛点揭开：身心巨变的真实深渊 (15%~35%)]
- 生理风暴白描：深夜潮热盗汗突醒、白天莫名心慌乏力、琐事情绪崩溃
- 微观案例与承重物象：主持人李静2024直播发布会突然全身暴汗、大脑空白，空调强劲却如进桑拿房，急中生智借“羊绒衫质量太棒”掩饰提前退场；半夜两点惊醒，严重职业倦怠
- 典型案例 2：46岁樱桃妈与女儿“青春期撞上更年期”，摔杯大哭

[节拍 3: 社会机制剖析：2.1亿人群的病耻与失语 (35%~60%)]
- 权威数据锚点：2030年中国进入更年期预计2.1亿人，46.3%症状率，平均46岁进入围绝经期
- 科学规律科普：月经乱了就已开始，绝非停经才开始，长达2~7年
- 职场与社交失语：六层楼舅妈为看清字换大屏手机不敢说老花眼；脱口秀房主任回避被称“没素质老太太”

[节拍 4: 群像破冰与四步科学突围 (60%~85%)]
- 公开谈论的女性榜样：58岁那英随身带更年期调理药记心情日记，颜丙燕大方微笑谈停经
- 四步具体行动指引：
  1. 主动搜索一次（了解本地围绝经期门诊）
  2. 闺蜜群聊一次（打破“只有我这样”的孤岛感）
  3. 专业医疗与激素替代（希拉·德利兹《炙热的你》、黄圣依母亲公开案例）
  4. 身心度假疗愈（与山川河海链接，重获松弛）

[节拍 5: 认知升华：生命盛宴重塑 (85%~100%)]
- 身体赋权：不再为身体变化感到羞耻，真正成为身体的主人
- 观念颠覆：更年期不是人生的“废墟”，而是一场重新认领自我的人生盛宴
```

### 模式 G：【青年脱轨·反卷探寻与生活重建型】（2026 新增范例：《从上海白领到监狱囚犯》）
```markdown
[节拍 1: 极致身份反差切入 Hook (0%~15%)]
- 身份反差：名校复旦毕业生，放弃上海升职白领，揣200美元飞新西兰；从格子间主管到古堡监狱扮鬼“囚犯”
- 核心先导词：“淡班味”、“脱轨”

[节拍 2: 出走契机：洞察一眼望到头的牛马循环 (15%~30%)]
- 现实死局：考研落榜、公司升职但背负房奴债务预设；知道不想要什么，但不知道想要什么
- 处置人生决绝动作：萧山机场出发，200美元，与父母告别午餐

[节拍 3: 第一重肉身实体磨砺：果园劳作与生理受挫 (30%~50%)]
- 初入异国窘迫：丢行李，奥克兰街头舍不得吃、最奢侈的50元盖浇饭
- 采摘奇异果生理极限白描：几十斤木箱勒疼肩膀、半蹲姿势导致痔疮发作、晨露未蒸发流入手套再流进腋下、手指泡发白
- 简单快乐回响：休息时咬下一口清甜猕猴桃

[节拍 4: 第二重荒诞奇遇：讨薪死磕与古堡牢房扮鬼 (50%~75%)]
- 剪枝死磕讨薪：清晨5点零下严寒剪枝，遭遇克扣工资，电话死磕“我就住在黑斯延斯跟你们没完”
- 内皮尔监狱扮鬼：住进泛着寒光铁门的古堡牢房；白色连体服；床底下三次吓游客的心理波折与滑稽逃窜

[节拍 5: 精神回归与生活之锚重建 (75%~100%)]
- 回国与转型：写下《打工旅行》、加入《孤独星球》调研、团队解散后转型悬疑小说家
- 核心哲学金句：音乐家墓碑碑铭“生命不在乎得到什么，只在乎做过什么”
- 留白定格：“和没有脱过轨的人相比，我脱过轨，知道未知没那么可怕”
```

### 模式 H：【创伤互救·生死承诺与无障碍环球跋涉型】（2026 新增范例：《完美恋人意外坠落后》）
```markdown
[节拍 1: 愿望清单与极光相约 Hook (0%~15%)]
- 浪漫开局：北京设计师阿秋与资深驴友何生结缘，随心飞一年72次，2000公里异地双向奔赴
- 核心物象：一张熠熠生辉的旅行愿望清单，极光、热气球与野生动物的约定

[节拍 2: 意外粉碎一切：高位截瘫与退缩 (15%~30%)]
- 意外降临：赴加留学前夕苏梅岛车祸，高位截瘫、左眼视神经不可逆损伤、右臂受损
- 情感爆破与反击：何生自卑提分手“做回朋友不拖累”，阿秋霸气反击：“做朋友太见外，你还是归我管比较好！”

[节拍 3: 泥潭中重铸尊严：生理极限与病房照护 (30%~50%)]
- 生理痛苦白描：反复破溃流血的压疮，大浴巾垫身小心翼翼拖进浴室洗澡
- 调侃与温情：阿秋跑调唱周杰伦《蜗牛》逗笑；导尿管、开塞露塞满十几公斤背包
- 动作突破：从坐起到双手撑上轮椅，右臂终于能抬起

[节拍 4: 轮椅丈量世界：无障碍环球远征 (50%~75%)]
- 渐进远征：海南沙滩试水海风吹拂；波士顿纽约狂奔赶火车双手摇轮磨破出血；多伦多校园轮椅漫游打破“如果”
- 旅途挫折与互换：埃及金字塔小黄狗自由跳跃；维也纳坐8趟公交抢修轮椅轮圈辐条，雪中起舞

[节拍 5: 极光赴约与重回起点 (75%~100%)]
- 挪威雪地成全：何生酒店守候，阿秋楼下见证极光大爆发
- 重回起点：2025自驾重访丽江洱海与318川藏线，七年初心不改
- 留白余韵：“一场跨越七年的旅行梦，最好的结局，从来都是与他并肩”
```

### 模式 I：【味觉寻根·孤女亲情抚慰与文旅美食叙事型】（2026 新增范例：《中秋，1007公里》）

```markdown
- 致命巨变：1999年盛夏父母车祸双亡，孤女沈珂被接回洪湖舅舅家，紧绷失语
- 破冰瞬间：半夜11点舅妈端来藕汤面：“吃饱了才有力气想妈妈”；一碗面把她从绝境里捞出来

[节拍 3: 水乡场域沉浸：金湾夕阳与瞿家湾老街 (35%~60%)]

[节拍 4: 非遗美食矩阵与文旅赋能 (60%~85%)]

- 文旅联动：湖北文旅请客吃藕汤面，水乡秋意

[节拍 5: 余韵收束 (85%~100%)]
- 人间至味是这一碗藕汤面，风里备好了一整个季节的鲜美，有人等你回家
```

### 模式 J：【中年断崖·中产坍塌与亲情重构突围型】（2026 新增范例：《40岁失业那天》）

```markdown
- 绝境爆破：离职协议签字当天，龙岗大道宾馆开房，吞下一整瓶药寻死

[节拍 2: 阶层攀爬：农村做题家的黄金十年 (15%~35%)]
- 起点与荣光：陕北贫困县985硕士，入职深圳大厂10年带30人研发团队，买两套房，资助老家
- 隐患埋伏：女儿作文“我的爸爸是组数字：房贷、车贷、补习费”

- 妻子行动：重返职场应聘幼儿园生活老师，分担家庭日常
- 老父存折：父亲拿出十多年分文未动的存折，足抵3年房贷

[节拍 5: 理性重生与务实突围 (80%~100%)]
- 创业起步：自筹资金创办中小网站外包公司，专门招募有经验的中年员工
- 认知重塑：关注理财抗风险，“在死亡面前，唯有亲情是落魄时唯一不退缩的底气”
```

### 模式 K：【生态反转·体制脱轨与双向奔赴科考型】（2026 新增范例：《考公失败后》）
```markdown
[节拍 1: 考公失败与不可理喻的进山 Hook (0%~15%)]
- 偏见冲突：农大生科保研学长林深考公失败去神农架当护林员，女友初访斥其“没苦硬吃”，两人渐行渐远
```
